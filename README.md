# Football Manager Lite ⚽

משחק ניהול כדורגל מקורי בעברית. נהל קבוצה מאחת מחמש הליגות הבכירות
באירופה (אנגליה, ספרד, גרמניה, איטליה, צרפת), שפר את הסגל שלך דרך
שוק ההעברות, קבל החלטות באירועים מיוחדים, נהל תקציב ונסה לזכות
באליפות - הכל מהדפדפן, בלי שרת, עם שמירה אוטומטית.

## הפעלה מקומית

המשחק הוא אתר סטטי טהור (HTML/CSS/JavaScript עם ES Modules) - אין
צורך בבנייה (build) או בהתקנת חבילות כדי להריץ אותו. מכיוון
שהמודולים נטענים עם `fetch`, יש להריץ אותו משרת סטטי מקומי (לא לפתוח
את `index.html` ישירות מהדיסק):

```bash
# מכל תיקיית הפרויקט:
python3 -m http.server 8000
# או
npx serve .
```

ואז פתחו בדפדפן: `http://localhost:8000`

## הרצת בדיקות

הבדיקות (unit tests) כתובות עם `node --test` המובנה של Node.js
(גרסה 18 ומעלה), ובודקות את כל מנגנוני הליבה (משחק חדש, סגל, שוק
העברות וקיזוז מחירים, סימולציית מחזורים, אירועים, כלכלה, סיום עונה
ופשיטת רגל) ללא תלות בדפדפן:

```bash
npm test
```

כל 20 הבדיקות אמורות לעבור. יש גם בדיקת עומס (`tests/stress.test.js`)
שמריצה עשרות עונות עם seeds אקראיים שונים ומוודאת שאינוריאנטים
בסיסיים (4 שחקנים בסגל, כושר/יכולת בטווח, בלי שחקן כפול) נשמרים
לאורך כל הדרך.

## מבנה הפרויקט

```
players.json            מאגר 250 השחקנים (קובץ מקור - לא נגעתי בו)
index.html               נקודת הכניסה
manifest.json, sw.js      תמיכת PWA (התקנה למסך הבית, פעולה אופליין בסיסית)
css/style.css             כל העיצוב (RTL, רספונסיבי)
js/data/                  נתונים סטטיים: ליגות וקבוצות, הגדרות כלכליות, הגדרות אירועים
js/engine/                לוגיקת המשחק הטהורה (ללא תלות ב-DOM, ניתנת לבדיקה):
  playersRepo.js             שאילתות על מאגר השחקנים + בדיקת תקינות
  newGame.js                 יצירת משחק חדש
  squad.js                   ניהול סגל, שכר, כושר
  fixtures.js                בניית לוח מחזורים (round robin)
  table.js                   טבלת ליגה
  simulate.js                סימולציית משחקים
  economy.js                 הכנסות/הוצאות, שכר, פרסים, פשיטת רגל
  transferMarket.js          שוק העברות + נוסחת הקיזוז
  events.js                  מנוע האירועים המיוחדים
  seasonEnd.js                סיום עונה ומעבר לעונה הבאה
  round.js                    הבקר המרכזי של התקדמות מחזור (orchestrator)
  save.js                     שמירה/טעינה מ-localStorage
  controller.js                מחבר הכל יחד + שמירה אוטומטית אחרי כל פעולה
js/ui/                    שכבת התצוגה (render.js מייצר HTML, app.js מטפל באירועי לחיצה)
tests/                    בדיקות node --test
```

## הערה על מבנה הליגה (11 קבוצות, 11 מחזורים)

הבקשה המקורית ציינה 11 קבוצות בליגה עם 10 מחזורים, כך שכל קבוצה
תשחק פעם אחת נגד כל אחת מהאחרות ללא משחקים כפולים. מתמטית, עם מספר
אי-זוגי של קבוצות (11), אי אפשר שכל הקבוצות ישחקו בכל מחזור בלי
חזרות - חייב להיות "מחזור מנוחה" לקבוצה אחת בכל מחזור (בדיוק כמו
בליגות אמיתיות עם מספר אי-זוגי של משתתפים). לכן המשחק משתמש ב-11
מחזורים: בכל מחזור קבוצה אחת נחה, וקבוצת השחקן עצמה משחקת בדיוק 10
משחקים (נגד כל 10 היריבות, פעם אחת) - בדיוק כפי שהתבקש. הפירוט המלא
נמצא בהערה ב-`js/data/settings.js`.

## פריסה ל-Vercel

1. דחפו את הפרויקט לריפוזיטורי ב-GitHub.
2. ב-Vercel: "New Project" → יבוא הריפו → אין צורך בשום הגדרת Build
   Command או Output Directory (זהו פרויקט סטטי, `vercel.json` כבר
   כולל את הגדרות ה-headers המומלצות).
3. פריסה (Deploy). זהו.

## PWA - התקנה למסך הבית

האתר כולל `manifest.json` ו-Service Worker בסיסי (`sw.js`) שמאפשרים
התקנה למסך הבית בטלפון אנדרואיד (ובדומה גם ב-iOS דרך "הוספה למסך
הבית" בספארי) והפעלה אופליין חלקית של הנכסים הסטטיים. המשחק עצמו
אינו תלוי ברשת כלל מעבר לטעינה הראשונית של הקבצים.

## שמירה

המשחק שומר אוטומטית ל-`localStorage` אחרי כל פעולה שמשנה את מצבו
(רכישה, מחזור, אירוע וכו'). אין כפתורי שמירה/טעינה ידניים.
